## 1. Replace create-drop with Flyway

```properties
spring.jpa.hibernate.ddl-auto=validate
```

| Key                 | Why we use it                                                   |
| ------------------- | --------------------------------------------------------------- |
| `ddl-auto=validate` | Hibernate checks mappings but does not create/change the schema |
| Flyway migrations   | Version and apply schema changes in order                       |

Flyway now owns the schema, and Hibernate checks it instead of creating it.

## 2. Add the migration scripts

```sql
-- CREATE TABLE defines a database table; PRIMARY KEY identifies each row.
CREATE TABLE book (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title VARCHAR(255),
    author_id BIGINT,
    price DECIMAL(10,2)
);
```

| SQL Key       | Why we use it                            |
| ------------- | ---------------------------------------- |
| PRIMARY KEY   | Uniquely identifies a row                |
| IDENTITY      | Lets PostgreSQL generate an id on insert |
| DECIMAL(10,2) | Stores money with two decimal places     |

This keeps the database structure versioned and repeatable.

## 3. Use Postgres for real deployments

```bash
docker compose up -d
```

Then point the app at PostgreSQL via environment variables.
