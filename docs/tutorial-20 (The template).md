# Tutorial 20 — The template

Turn this project into a repeatable backend starter.

---

## 1. What carries over

The reusable parts are the app structure, configuration pattern, auth flow, API envelope, security setup, Flyway migrations, and test layout.

## 2. How to start a new project

1. Copy the repo.
2. Rename the package and artifact.
3. Replace the domain model with your own entities.
4. Keep the shared infrastructure: auth, validation, error handling, config, security, tests.

## 3. Final note

This project is now a practical starter template, not just a tutorial app.
